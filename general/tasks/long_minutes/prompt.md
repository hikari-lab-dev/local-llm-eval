minutes_2026.md は合唱団の 1 年分（50 回）のミーティング記録です。記録全体を読んで、次の 2 つのファイルを作ってください。

1. answers.json（形式は下記）

```json
{
  "current_fee": 現在の月額会費（円、整数）,
  "fee_proposer": "現在の会費額を提案した人の姓",
  "location_changes": 常設の練習場所が変更された回数（整数）,
  "current_location": "現在の常設の練習場所",
  "concert_date": "演奏会の開催日（YYYY-MM-DD）",
  "concert_decided_on": "演奏会の開催日が正式に決まったミーティングの日付（YYYY-MM-DD）",
  "score_purchase_total": 楽譜購入として承認され、取り消されていない金額の合計（円、整数）,
  "new_members_total": 入団が承認された人数の合計（整数）
}
```

2. summary.md: 団員向けに、この 1 年で決まった重要事項（会費・練習場所・演奏会・楽譜購入・団員の増減）を 400 字以内の日本語でまとめる

注意: 提案・保留・否決・取消・一時的な変更は、決定とは区別してください。
