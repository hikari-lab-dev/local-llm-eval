notes/ フォルダに Markdown のメモが 25 件あります。各メモの先頭には `tags: [...]` の形でタグがあり、本文の `[[メモ名]]` は他のメモ（notes/メモ名.md）へのリンクです。次の 3 つを調べ、index.json に書いてください。

```json
{
  "tags": {"タグ名": そのタグが付いたメモの件数},
  "broken_links": [{"from": "リンク元のファイル名（例: note-01.md）", "to": "存在しないリンク先のメモ名"}],
  "orphans": ["他のどのメモからもリンクされていないメモのファイル名"]
}
```

- broken_links は from、to の順で並べ替える。orphans はファイル名順に並べる
- 存在しないメモへのリンクは、リンク元にとっては被リンクの計算に含めない
