# 課題: CSV1行パーサー

`CsvParser/CsvLineParser.cs` の `CsvLineParser.ParseLine` メソッドを実装してください。

## 入力フォーマット

- フィールドはカンマ（`,`）区切り。
- フィールドは二重引用符（`"`）で囲むことができる。囲まれたフィールドの中ではカンマをそのまま含められる。
- 引用符で囲まれたフィールド内で `""`（二重引用符を2つ連続）が現れた場合は、
  エスケープされた1個の `"` として扱う。
- 引用符はフィールドの先頭にある場合のみ「引用符付きフィールドの開始」として扱う
  （先頭以外に現れる `"` の扱いは考慮しなくてよい）。
- 空文字列の入力は要素数1・値が空文字列のリスト（`[""]`）を返す。
- 末尾がカンマで終わる場合、最後のフィールドは空文字列になる。

## 戻り値

- 分割されたフィールドの文字列リスト（`List<string>`）。

## 制約

- `tests/CsvLineParserTests.cs` は既存のテストです。実装がこれを壊さないようにしてください。
- 外部 NuGet パッケージの追加は不要です。
