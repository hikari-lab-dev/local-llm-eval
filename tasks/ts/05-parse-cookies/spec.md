# 課題: Cookie ヘッダーのパース

`cookies.ts` の `parseCookieHeader` 関数を実装してください。

## 入力フォーマット

- 入力は HTTP の `Cookie` ヘッダー相当の文字列（例: `"a=1; b=2; c=hello%20world"`）。
- `;` で区切られた各セグメントを `key=value` として解釈する。
- キー・値それぞれの前後の空白（半角スペース）は取り除く。
- 値は `decodeURIComponent` でデコードする。
- 値自体に `=` が含まれてもよい。その場合、セグメント内の**最初の** `=` をキーと値の区切りとする
  （例: `"token=abc=def"` → キー `token`、値 `abc=def`）。

## 無視するセグメント

- `=` を含まないセグメントは無視する。
- キー部分がトリム後に空文字になるセグメント（例: `"=value"`）は無視する。

## 重複キー

- 同じキーが複数回現れた場合は、**最初に**出現した値を採用し、以降は無視する。

## 戻り値

- `Record<string, string>`。
- 入力が空文字列、または有効なセグメントが1つも無い場合は空オブジェクト `{}` を返す。

## 制約

- 標準ライブラリのみ使用可能（追加パッケージ不可）。
- `tests/cookies.test.ts` は既存のテストです。実装がこれを壊さないようにしてください。
