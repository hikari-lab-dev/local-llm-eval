# 課題: 経過時間のフォーマット

`duration.ts` の `formatDuration` 関数を実装してください。

## 仕様

- 引数 `totalSeconds` は 0 以上の整数（秒）。
- 出力は日(d) / 時(h) / 分(m) / 秒(s) を組み合わせた文字列。
  - 1日 = 86400秒、1時間 = 3600秒、1分 = 60秒として計算する（うるう秒等は考慮しない）。
  - 値が0の要素は出力から省略する。
  - ただし `totalSeconds` が0の場合は `"0s"` を返す。
- 出力する要素は d, h, m, s の順に並べ、要素間は半角スペース1つで区切る。
- 各要素の表記は `<数値><単位1文字>`（例: `2d`, `1h`, `30m`, `5s`）。前ゼロ埋めはしない。

## 例

- `0` → `"0s"`
- `45` → `"45s"`
- `90` → `"1m 30s"`
- `3661` → `"1h 1m 1s"`

## 制約

- 標準ライブラリのみ使用可能（追加パッケージ不可）。
- `tests/duration.test.ts` は既存のテストです。実装がこれを壊さないようにしてください。
