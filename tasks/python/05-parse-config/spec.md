# 課題: 簡易設定ファイルパーサー

`config_parser.py` の `parse_config` 関数を実装してください。

## 入力フォーマット

- `[section]` でセクションを開始する。
- `key = value` で値を設定する（`=` の前後の空白は無視する）。
- `#` から行末まではコメントとして無視する（行の途中に現れた場合も同様）。
- 空行（コメントのみの行含む）は無視する。
- セクション外に `key = value` が現れることはない（入力として想定しない）。

## 値の型変換

- `true` / `false`（大文字小文字を区別しない）は `bool` に変換する。
- 整数として解釈できる値（例: `42`, `-3`）は `int` に変換する。
- 浮動小数点として解釈できる値（例: `3.14`）は `float` に変換する。
- 上記のいずれにも当てはまらない値は文字列のまま（前後の空白は取り除く）。

## 戻り値

- `{セクション名: {キー: 変換後の値}}` の辞書。
- 同じセクションが複数回登場した場合は、キーをマージする（後勝ち）。

## 制約

- `tests/test_config_parser.py` は既存のテストです。実装がこれを壊さないようにしてください。
- 標準ライブラリのみ使用可能。
