# 課題: 区間のマージ

`intervals.py` の `merge_intervals` 関数を実装してください。

## 仕様

- 入力は `(start, end)` のタプルのリスト（`start <= end`）。開始順にソートされているとは限らない。
- 重なっている区間、および端点が接している区間（例: `(1, 3)` と `(3, 5)`）は1つに結合する。
- 戻り値は `start` の昇順でソートされた、重複のない区間のリスト。
- 入力が空リストの場合は空リストを返す。

## 制約

- 標準ライブラリのみ使用可能。
- `tests/test_intervals.py` は既存のテストです。実装がこれを壊さないようにしてください。
